## What it is
Telegram is an instant messaging app, package name `org.telegram.messenger`. For website knowledge see `telegram.org`.

## UI
There are Chats (the conversation list), Contacts and a new-message entry; a new message can start by choosing a person from contacts or search. The page you land on after entering is not necessarily Chats.

## Features
- **Reading messages**: find the target in the conversation list and enter it, then scroll to view the history; each message has a sender and a time. Groups, channels and contacts are different kinds of objects.
- **Sending messages**: type in an existing conversation, or choose a recipient from Contacts or the new-message entry. After sending, a new message bubble appears in the conversation. On the contacts page you can view contact profiles.
