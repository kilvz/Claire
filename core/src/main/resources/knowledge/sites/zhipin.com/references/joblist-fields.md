# Fields of each job in the job list API

In `zpData.jobList` returned by `/wapi/zpgeek/search/joblist.json`, each job has:

`jobName`, `salaryDesc` (the plain-text salary, such as 「40-70K·15薪」 (40-70K, 15 months' pay)), `brandName`, `brandScaleName`, `brandStageName`, `brandIndustry`, `cityName`, `areaDistrict`, `businessDistrict`, `jobExperience`, `jobDegree`, `skills`, `welfareList`, `jobLabels`, `bossName`, `bossTitle`, `bossOnline`, `encryptJobId`, `securityId`, `lid`, `itemId` (its index in the list).
