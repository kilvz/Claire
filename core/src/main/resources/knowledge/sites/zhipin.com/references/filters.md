# Filter codes

The codes for the search page filter options come from the site's public filter table (`/wapi/zpgeek/search/job/condition.json`). The parameter in parentheses in a heading is the one that appears in the URL after that item is selected on the page; where no parameter is written, it has not been verified in the URL. A code of 0 for 「不限」 (No limit) means the parameter is not included.
