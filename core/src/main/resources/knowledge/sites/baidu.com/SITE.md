## What it is
Baidu Search is a general search website where you can look up web pages, news and common knowledge. Rankings such as Baidu hot search are on the separate `top.baidu.com` website.

## Pages and URLs
- Home page: `https://www.baidu.com/`.
- Search results: `https://www.baidu.com/s?wd=<URL-encoded keyword>`.

## Features
- **Keyword search**: basic search and public results need no login. Results change with the keyword, time and page version.
- **Integrated answer**: for some keywords the results page first gives an integrated piece of content, with the remaining results and entries below or beside it on the same page.

## Known issues
The home page and search results contain dynamic content; reading only the page header or footer does not mean the search has no results. The results page should be judged by the keywords, answers and result entries that actually appear.
