## What it is
A globally used instant messaging service. The web version `web.whatsapp.com` shares the same account with the phone and desktop apps.

## Pages and URLs
Web version entry `https://web.whatsapp.com/`. When not linked, the page shows a QR code; scan it with 「关联设备」 (Linked devices) in WhatsApp on the phone. After signing in, the left side has the conversation list and the search and new chat buttons, and the right side is the chat window. The interface language follows the browser.

## Features
- **Reading**: the conversation list shows the title and the last message; opening a conversation shows the body text and times, and in group chats you can see which members spoke.
- **Sending messages**: for an existing conversation, type in the input box at the bottom and send; start a new chat from New chat or by searching for a contact.

## Known issues
Linked-device sign-in relies on a QR code, and it and phone-number verification codes are two different verifications. With the newer linking method, the phone does not have to stay online all the time.
